# Music Playlist App

A simple Music Playlist App built using Vite and React.js.

## Features

- View songs in a playlist
- Search songs by title or artist
- Add new songs
- Play a selected song
- Add songs to favorites
- Remove songs from favorites
- Delete songs
- Clear search results

## Technologies Used

- React.js
- Vite
- JavaScript
- HTML
- CSS

## React Concepts Used

This project demonstrates basic React concepts such as:

- `useState`
- Components
- Props
- Event handling
- Conditional rendering
- `map()`
- `filter()`

## Components

### App.jsx

The main component of the application. It manages the playlist data and application states.

### SongItem.jsx

Displays each song and provides buttons for Play, Favorite, and Delete.

### AddSong.jsx

Contains the form for adding a new song.
